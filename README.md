# FC Tutoring Lessons Repository

This repository contains code, exercises, notebooks, and additional materials used during the **FC tutoring sessions at the University of Cagliari**.

The repository will be updated throughout the course as new topics are covered and new materials become available.

## Tutoring Hours

Tutoring sessions are held every **Friday from 9:00 AM to 11:00 AM** in **Aula 209 @ Blocco A**.

Any changes to the schedule will be communicated in advance.

## Getting Started

If you are attending the tutoring sessions, you can find the material for each topic in the corresponding directory or notebook.

If you prefer to work on your own laptop, make sure that your Python environment is correctly configured. A step-by-step installation guide is available here:

[Python Setup Guide](Setup_di_Python.md)

## Contents

The repository is organized progressively according to the topics covered during the tutoring sessions.

- **0a. Environment Setup**  
  [Python Setup Guide](Setup_di_Python.md) — Instructions for setting up Python, Miniforge, and VS Code.

- **0b. Introduction to Python**  
  [Python Introduction](Intro_Python.ipynb) — A brief introduction to the Python language and its basic concepts.

- **1. Basic Examples**  
  [02/10 Tutoring](Tutoraggio_02.10) — Basic Python examples, user input, functions, and a free-fall exercise.

- **2. Physical Applications and Numerical Integration**  
  [09/10 Tutoring](Tutoraggio_09.10) — Satellite orbital height, wave interference, and integration of velocity data using the trapezoidal rule.

- **3. Comparing Integration Methods**  
  [21/10 Tutoring](Tutoraggio_21.10) — Midpoint, trapezoidal, Simpson's, and Gaussian quadrature methods, with relative-error comparisons. Includes the `gaussxw.py` helper for Gaussian quadrature.

- **4. Nonlinear Equations and Minimization**  
  [06/11 Tutoring](Tutoraggio_06.11) — Fixed-point iteration for a phase-transition model and golden-section minimization of the Buckingham potential.

- **5. Differential Equations: RC Low-Pass Filter**  
  [13/11 Tutoring](Tutoraggio_13.11) — Fourth-order Runge–Kutta integration of an RC circuit driven by a square wave, with comparisons of time constants and numerical stability for different time steps.

_... More to come ..._
